# In focus review: 6 October 2026

Edition reviewed 6 October 2026, runs to 3 November 2026. Nine questions. It
replaces the 21 September edition (expired 28 September), after which the
welcome card showed only a "pending" notice for a week. The 28 September draft
was not shipped: its questions pointed at announcements whose contents were
not checked, and none of the sources was a document the library holds.

From this edition the card keeps offering an expired edition's questions under
"Suggested", with the date the sources were last checked, instead of going
blank. Editions now run about a month, and a different question leads each
day.

## Checks

Every source URL was fetched on 6 October 2026 and returned a PDF (HTTP 200).
Every question was run through the agent's first search (`_search_corpus`,
hybrid retrieval on, keyword RPC v2) and its own source came back first.

Considered and dropped: the Access to Information Act, 2023. It commences by
ministerial statutory instrument, no commencement order is held, and an answer
quoting its seven-day deadline would mislead if it has not started.

## Library gaps found

The library's chunks for the Data Protection Act, 2021, the Access to
Information Act, 2023 and the National Pension Scheme Act, 2026 hold the
section 1 heading but not its text, so the commencement clause is invisible to
the agent. The official PDFs have it.
